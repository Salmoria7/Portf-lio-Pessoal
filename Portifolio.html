Projeto de HTML e CSS

Descrição do meu projeto:

Este projeto é um exemplo de como criar uma página de receita de bolo simples usando HTML e CSS. Ele inclui uma estrutura básica com um cabeçalho, um corpo principal e um rodapé. O objetivo é demonstrar o uso de tags HTML para organizar o conteúdo e aplicar estilos básicos com CSS.

O projeto foi desenvolvido para praticar habilidades de desenvolvimento web, incluindo a criação de layouts responsivos e a aplicação de estilos visuais.

Link para o projeto: https://salmoria7.github.io/Site-de-Receita/

Projeto de SQL

Descrição do meu projeto:

Este projeto é um exemplo de como criar um banco de dados simples usando SQL. Ele inclui a criação de tabelas, inserção de dados e consultas básicas. O objetivo é demonstrar o uso de comandos SQL para gerenciar e manipular dados em um banco de dados relacional.

Abaixo estará os códigos SQL utilizados no projeto:

create database LocadoraVeiculos; use LocadoraVeiculos; create table Cliente(
idCliente int not null primary key,
CPF varchar (20) not null,
nome varchar (50) not null,
telefone varchar(20) not null,
email varchar (50) not null,
endereco varchar (100)not null
);
create table Pagamento (
idPagamento int not null primary key,
forma enum ('Cartão','Pix','Dinheiro') not null,
dataPagamento date not null,
valorTotal decimal (7,2) not null,
estado enum ('Pago','Pendente') not null
);
create table Veiculo (
idVeiculo int not null primary key,
] modelo varchar(50) not null,
marca varchar(50)not null,
ano int not null,
placa varchar (10) not null,
valorDiaria decimal (7,2) not null,
estado enum ('Disponível','Alugado','Manutencao' ) not null
);
create table Locacao(
idLocacao int not null primary key,
idCliente int not null,
idPagamento int not null,
dataInicio date not null,
dataFim date not null,
foreign key (idCliente) references Cliente (idCliente),
foreign key (idPagamento) references Pagamento (idPagamento)
);
create table LocacaoVeiculo(
idLocacao int not null ,
idVeiculo int not null,
foreign key (idLocacao) references Locacao (idLocacao),
foreign key (idVeiculo) references Veiculo (idVeiculo)br );
create table Manutencao(
idManutencao int not null primary key,
idVeiculo int not null,
descricao varchar (100) not null,
dataManutencao date not null,
custo decimal (7,2) not null,
foreign key (idVeiculo) references Veiculo (idVeiculo)br );

Imagens das pesquisas realizadas

Total Arrecadado

SELECT SUM(valorTotal) AS total_arrecadado
FROM pagamento
WHERE estado <> 'pendente';

Total de Locacoes por Veiculo

SELECT c.nome, SUM(p.valorTotal) AS valor_devido
FROM
Cliente c
JOIN
Locacao l ON c.idCliente = l.idCliente
JOIN
Pagamento p ON l.idPagamento = p.idPagamento
WHERE
p.estado = 'Pendente'
GROUP BY
c.nome ,
ORDER BY
c.nome ASC;
select * from pagamento;
